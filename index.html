Long story packs

Each pack is a story split into scenes. Copy one scene at a time into your AI video tool, then join the clips in a video editor and add a voiceover. The character description is added to every scene automatically so the character stays the same.

UK Audience

A separate section for UK viewers and a worldwide audience: funny 3D cartoon shorts starring dogs, one long story, and realistic British footage prompts. Everything is written in UK English, whatever video language is selected above. Roman Urdu notes are included so you can follow each idea.

How the system works:
  • Use the same four characters in every episode. Paste their description into each prompt so they always look the same.
  • Make the joke visual first. Use at most one short spoken line, so viewers in any country understand it.
  • Keep each short 15 to 30 seconds and end on the same frame you started with, so it loops.
  • Write voiceover and captions in UK English: colour, favourite, queue, biscuit, football, chips, bus. Always add subtitles.
  • Post one new episode every day at about the same time.
